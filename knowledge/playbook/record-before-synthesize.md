# Record and transcribe every interview before synthesis starts

No exceptions, even under deadline pressure. A synthesis draft built from handwritten notes
instead of the transcript nearly went to a client with a lost deal mischaracterized — the
analyst's memory of the call didn't match what the respondent actually said. Priya now checks
for a transcript link before marking a project ready for review, which closes the gap instead
of relying on the analyst to remember.
